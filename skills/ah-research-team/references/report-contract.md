# 一体化公司研究报告契约

报告标题注明公司、证券代码、研究日和价格时点。章节可以因公司特点调整，但必须完整回答以下问题，且不得按研究角色逐一汇报。

## 1. 核心结论与主要矛盾

- 企业质量：优秀 / 良好 / 一般 / 较弱 / 证据不足，并说明判断依据。
- 增长势头：加速 / 稳定 / 放缓 / 反转 / 无法判断；区分同比基数、周期波动和结构性趋势。
- 估值状态：有吸引力 / 合理 / 偏贵 / 显著透支 / 无法可靠估值。
- 市场计价：尚未充分反映 / 部分反映 / 大致充分反映 / 过度反映 / 证据不足。
- 一句话 thesis、最重要的主要矛盾、两到三条决定性证据和最强反证。
- 研究周期及其选择理由。

以上维度不得压缩成一个无解释的综合分。

## 2. 商业模式与价值驱动

解释客户是谁、解决什么问题、如何收费、收入与利润来自哪里、成本和资本投入流向何处、竞争优势如何转化为 ROIC 或自由现金流。按公司业务拆分关键分部，并指出哪些业务创造价值、消耗价值或提供期权。

列出真正有解释力的 company-specific KPI，说明每项 KPI 与收入、利润、现金流或估值的传导关系；不要用通用财务比率代替业务理解。

## 3. 盈利能力、质量与财务变化

覆盖增长质量、利润率、ROIC/ROE、现金转换、资产负债表、资本开支、资本配置和治理。至少比较多个报告期，说明变化方向、来源、持续性及会计口径；重要异常必须追溯到原始披露。

## 4. 增长点与增长势头

逐项拆解当前和潜在增长驱动，回答：市场空间、公司抓取能力、当前贡献、兑现节奏、领先指标、边际变化、利润与现金流贡献、已经兑现多少、证伪条件。明确区分确定性较高的核心增长、尚需验证的可选项和单纯叙事。

## 5. 竞争与可比基准

若同业比较有信息价值，只展示能改变结论的可比维度，并解释对象为何可比及口径差异。若公司业务独特或可比对象失真，说明不强行横比的理由，改用自身历史、单位经济、分部或情景基准。

## 6. 股价反映了多少

说明当前价格隐含的增长、利润率、ROIC、资本开支或业务寿命假设，并与公司指引、一致预期、预期修正和历史事件反应交叉验证。结论采用可解释的状态或区间，不伪造单一精确百分比。必须明确哪些增长点已被计价、哪些仍存在预期差、哪些可能被高估。

## 7. 估值、安全边际与价格区间

- 说明所选估值方法和排除其他方法的理由。
- 列出 bull/base/bear 的经营假设、估值结果、概率或权重依据；无法支持概率时只给情景区间。
- 解释安全边际如何由企业质量、周期性、预测确定性、财务与治理风险共同决定。
- 在数据允许时给出理想买入上限、可接受买入上限、合理持有区间和估值偏贵/卖出复核区间，注明币种与估值基准日。
- 卖出复核同时包含估值过度透支和基本面证伪条件，不涉及卖出比例。
- 数据不足时列出缺失输入及条件式计算，不得编造目标价。

## 8. 风险、催化剂与复核

风险按 `发生机制 / 领先信号 / 影响路径 / 当前证据 / 证伪或缓释条件` 表述，避免通用清单。列出未来催化剂、thesis invalidation、最有信息价值的未知量、关键监测 KPI 和下一次复核事件。

## 9. 证据边界与来源

列出研究日、行情时点、最近财报期、stale 或非 point-in-time 数据和关键缺口。事实、分析推断、情景假设必须能区分。正文附近引用最少但足够的原始链接，不把所有来源堆在文末才说明。

报告不得包含目标仓位、调仓比例、组合权重、集中度建议、订单计划、逐角色得分表或 Portfolio Manager 裁决。
