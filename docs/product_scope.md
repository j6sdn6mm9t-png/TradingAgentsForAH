# 当前产品范围与数据路线

## 已确认需求

- 用途：全面理解一家 A 股或港股公司，并判断其合理估值。
- 研究周期：由商业模式、行业周期、盈利兑现路径和关键事件决定。
- 研究内容：商业模式、公司特定 KPI、盈利质量、增长点与势头、市场隐含预期、估值、安全边际、风险与证伪。
- 产品形态：Codex 对话中的自适应研究团队是主入口；Web 是可选报告查看器。
- 明确排除：目标仓位、调仓比例、组合集中度和订单执行建议。

## 核心交互

1. 用户输入公司名或证券代码，以及可选的原始 investment thesis。
2. Evidence Desk 准备行情、财务与估值快照，并从法披、交易所和公司 IR 补充原始证据。
3. Research Lead 建立公司研究蓝图：商业类型、主要矛盾、研究周期、关键 KPI、是否需要同业比较、必要研究角色。
4. 动态选择的研究能力完成取证和独立挑战；没有信息增量的角色不加入。
5. 估值模块用适合该公司的方式建立 bull/base/bear 情景、反向估值、动态安全边际和价格区间。
6. Report Editor 输出一体化公司报告，不展示内部角色流水账。

## 数据路线

### 当前原型

1. AkShare 获取 A/H 日线；当日研究可获取最新聚合财务和估值，并标记为非历史 PIT 数据。
2. A 股公告以巨潮资讯及交易所披露为一手证据；港股公告以 HKEXnews 与公司 IR 为一手证据。
3. 聚合快照用于发现问题，不足以单独支持商业模式、增长动能或内在价值结论。
4. 无可靠情景价值时报告保留价格区间缺口，不用统一 PE/PB 阈值补齐。

### 需要扩展的结构化数据

| 研究问题 | 最低数据要求 |
|---|---|
| 商业模式 | 分部收入/利润、客户与收费模式、价值链、资本投入 |
| 盈利质量 | 多期利润率、ROIC/ROE、现金转换、资产负债表、资本配置 |
| 增长势头 | 多期可比数据、贡献拆分、公司特定领先 KPI、管理层指引 |
| 市场计价 | 一致预期及修正、历史事件反应、自身估值历史、reverse valuation 输入 |
| 同业比较 | 业务重合度、期间/币种/会计口径归一化、增长阶段与风险暴露 |
| 估值区间 | 正常化盈利/现金流、bull/base/bear 假设、资本成本与终值 |
| 证据审计 | published_at、observed_at、period_end、单位、币种、口径、原文 URL |

供应商替换只改变数据适配层，不应改变公司自适应研究和报告契约。

## 不做的事情

- 不用当前财务快照回填历史日期。
- 不把 LLM 生成的数字当作数据源。
- 不用单期同比判断增长加速或减速。
- 不强制每家公司进行同业比较。
- 不把企业质量、增长、估值和价格动作折成一个总分。
- 不生成仓位管理或自动下单建议。
